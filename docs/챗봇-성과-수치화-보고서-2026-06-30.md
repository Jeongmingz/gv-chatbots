### 3.5 실제 효과 측정을 위한 추가 계측

다음 이벤트를 사용자 ID, 세션 ID, 원 FAQ 이력 ID와 함께 별도 저장해야 한다.

| 이벤트 | 저장 시점 | 목적 |
|---|---|---|
| `faq_response_shown` | FAQ 응답 반환 | 분석 분모 확정 |
| `faq_followup_clicked` | 관련 FAQ 선택 | 셀프서비스 지속 분석 |
| `handoff_shown` | 상담 버튼 노출 | 상담 기회 분모 확정 |
| `handoff_clicked` | 상담 버튼 선택 | 매칭 후 상담 전환율 계산 |
| `handoff_connected` | 상담 채널 진입 성공 | 실제 상담 연결률 계산 |
| `resolved_yes` | 해결됨 피드백 | FAQ 해결률 계산 |
| `resolved_no` | 미해결 피드백 | FAQ 실패율 계산 |
| `session_timeout` | 30분 무응답 | 종료 추정 보조 지표 |

계측 후 산출해야 할 핵심 KPI:

```text
FAQ 직접 해결률 = resolved_yes / faq_response_shown
매칭 후 상담 클릭률 = handoff_clicked / matched FAQ response
매칭 후 실제 상담 연결률 = handoff_connected / matched FAQ response
미매칭 후 상담 연결률 = handoff_connected / unmatched response
상담 억제율 = 1 - (매칭 후 실제 상담 연결률)
```

각 KPI에는 반드시 분석 시작일, 종료일, 테스트 호출 제외 조건, 세션 기준 및 최소 표본 수를 함께 표기해야 한다.
