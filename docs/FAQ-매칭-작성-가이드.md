# FAQ 매칭 작성 가이드

## 목적

이 문서는 고객 질문을 어떤 FAQ에 연결할지 결정하기 위한 작성 기준입니다.

직접 `data/*.json`을 수정하기 전에 `FAQ-매칭-작업표.md`에서 질문 묶음별 처리 방법을 선택하세요. 선택이 끝나면 그 내용을 기준으로 데이터 구조와 매칭 엔진을 반영할 수 있습니다.

## 질문 묶음별 선택 항목

각 질문 묶음에서 아래 네 가지 중 하나를 선택합니다.

| 선택 | 사용하는 경우 | 작성할 내용 |
|---|---|---|
| 기존 FAQ 연결 | 기존 답변이 질문에 정확히 대응함 | 연결할 FAQ ID |
| 새 FAQ 작성 | 기존 FAQ에 적절한 답변이 없음 | 질문 제목과 답변 |
| 확인 질문 | 모델이나 증상 정보가 없으면 답을 정할 수 없음 | 고객에게 물을 문장 |
| 상담원 연결 | 주문, 결제, AS 진행 상황처럼 개인정보 확인이 필요함 | 연결 사유 |

## 작성 순서

1. 같은 의도의 실제 고객 질문을 한 묶음으로 봅니다.
2. 묶음에 있는 질문들이 정말 같은 답변을 받아도 되는지 확인합니다.
3. 처리 방법 네 가지 중 하나를 선택합니다.
4. 기존 FAQ 연결이면 FAQ ID를 확인합니다.
5. 새 FAQ 작성이면 고객에게 보여줄 답변을 작성합니다.
6. 다른 FAQ와 혼동될 표현을 `제외 표현`에 적습니다.
7. 모델에 따라 답이 달라지면 확인 질문을 작성합니다.

## 같은 의도로 묶는 기준

표현이 달라도 최종 답변과 고객이 해야 할 행동이 같으면 같은 묶음입니다.

```text
가스리필 신청합니다
리필 실린더 주문하고 싶어요
충전 실린더 어디서 사요
```

위 질문들은 모두 `실린더 리필 구매`로 묶을 수 있습니다.

반대로 같은 단어를 사용해도 고객 행동이 다르면 분리해야 합니다.

```text
필터 어디서 사요        -> 필터 구매
필터 어떻게 갈아요      -> 필터 교체 방법
필터 청소 어떻게 해요   -> 필터 청소
필터 갈았는데 빨간불    -> 문제 해결
```

## FAQ별로 준비할 내용

### 1. Intent

`대상.행동` 또는 `대상.증상` 형식으로 작성합니다.

```text
cylinder.refill_purchase
filter.purchase
filter.replace
filter.alarm_after_replace
steam.no_output
```

### 2. 대표 발화

FAQ 하나당 최소 다섯 문장을 작성합니다.

- 정식 질문
- 짧은 질문
- 붙여 쓴 질문
- 오타가 있는 질문
- 상담하듯 작성한 긴 질문

```text
충전 실린더는 어떻게 구매하나요?
가스리필 신청합니다
리필실린더주문
가스 리필 신정할게요
실린더를 다 쓴 것 같은데 충전된 걸 새로 받고 싶어요
```

### 3. 필수 표현

답변을 결정하는 대상, 행동, 증상을 분리합니다.

```text
대상: 실린더, 가스, CO2
행동: 신청, 구매, 주문
증상: 없음
```

### 4. 제외 표현

비슷하지만 다른 FAQ로 가야 하는 표현입니다.

```text
교체, 장착       -> 실린더 교체 방법
잔량, 다 썼는지  -> 실린더 잔량 확인
반납, 수거       -> 빈 실린더 회수
```

### 5. 확인 질문

정보가 부족한 질문을 억지로 FAQ에 연결하지 않습니다.

```text
고객 질문: 빨간불이 들어와요
확인 질문: 사용 중인 모델명과 빨간불이 표시되는 위치를 알려주세요.
```

## FAQ로 연결하지 않는 메시지

아래 메시지는 FAQ 키워드를 추가하지 않습니다.

- 감사합니다, 고마워, 넵
- 입금했습니다, 입금자명 전달
- 주문번호만 적은 문의
- 사진·영상 URL
- AS 진행 상황과 회수 지연
- 제휴·공동구매 요청
- `문의`, `질문`, `FAQ`처럼 내용이 없는 메시지

이 메시지는 감사 응답, 첨부파일 처리, 주문 조회, 상담원 연결 등 별도 흐름으로 보냅니다.

## 검수 기준

작성이 끝난 묶음은 아래 기준을 모두 만족해야 합니다.

- [ ] 같은 묶음의 질문이 모두 같은 답변을 받아도 된다.
- [ ] 대표 발화가 5개 이상이다.
- [ ] 필수 대상과 행동 또는 증상이 정리돼 있다.
- [ ] 혼동 가능한 다른 FAQ와 제외 표현이 정리돼 있다.
- [ ] 모델 정보가 필요하면 확인 질문이 있다.
- [ ] 주문·결제·AS 진행 문의를 FAQ에 억지로 연결하지 않았다.
- [ ] 새 FAQ라면 고객에게 공개 가능한 답변이 작성돼 있다.

## 작성 예시

```text
[완료] 아르케 / 실린더 리필 구매

처리 방법: 기존 FAQ 연결
FAQ ID: aarke-refill-cylinder-purchase
Intent: cylinder.refill_purchase

대표 발화:
- 가스리필 신청합니다
- 리필 실린더 주문하고 싶어요
- 충전 실린더 어디서 사요
- 가스리필신청
- 빈 실린더가 있는데 리필 제품을 구매하고 싶습니다

필수 표현:
- 대상: 실린더, 가스, CO2
- 행동: 신청, 구매, 주문

제외 표현:
- 교체, 장착
- 잔량, 다 썼는지
- 반납, 수거

확인 질문: 없음
```
